# 서울시 보도자료 — 놓치지 않기

하루 2번(0시, 12시) 자동으로 서울시 보도자료를 가져와서,
- 주택·교통은 전부, 그 외 분야는 정책적으로 중요해 보이는 것만 골라서
- 제목 옆에 중요도 도장을 찍고
- 클릭하면 핵심 내용(□, ○ 로 시작하는 문장)을 바로 보여주는 사이트입니다.

첫 화면에서 서울시 사이트를 매일 다시 훑어볼 필요 없이, 이 페이지 하나만 확인하면 됩니다.

---

## 1단계. 새 저장소 만들기

1. github.com 로그인 후, 우측 상단 **+** → **New repository**
2. 이름은 원하는 대로 (예: `local-news-tracker`)
3. **Public** 선택 (GitHub Pages 무료 호스팅 조건)
4. **Create repository**

## 2단계. 파일 업로드

1. 저장소 페이지에서 **Add file → Upload files**
2. 이 폴더 안의 내용물(`.github`, `scraper`, `data`, `index.html`, `README.md`)을 **전체** 드래그해서 업로드
   - `.github` 폴더가 안 보이는 파일 탐색기라면 "숨김 파일 표시"를 켜주세요
     (Mac: `Cmd+Shift+.`, Windows 탐색기: 보기 → 숨긴 항목)
3. **Commit changes**

## 3단계. Actions 켜기 & 첫 실행

1. 저장소 상단 **Actions** 탭
2. "서울시 보도자료 수집" 워크플로우 클릭
3. 오른쪽 **Run workflow** → 다시 **Run workflow** (수동 1회 실행)
4. 1~2분 후 초록 체크(✅)가 뜨면 성공
   - 빨간 X가 뜨면 클릭해서 나오는 로그(빨간 글씨)를 통째로 복사해서 Claude에게 붙여넣어 주세요
5. 이후로는 매일 0시, 12시에 자동 실행됩니다 (별도 조작 불필요)

## 4단계. 웹사이트 켜기 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)** → **Save**
3. 1~2분 후 나오는 주소(`https://내아이디.github.io/저장소이름/`)로 접속

핸드폰 홈 화면에 즐겨찾기 해두면 앱처럼 바로 열립니다.

---

## 어떻게 작동하나요

- `scraper/scrape_seoul.py` 가 서울시 보도자료 목록을 훑어서 새 글만 골라내고,
  각 글의 상세페이지(`분류`, 본문 핵심 문장)를 가져옵니다.
- **중요도 판정 기준**
  - 분류가 `주택` 또는 `교통`이면 무조건 "높음"
  - 다른 분야라도 제목에 부동산·정비사업·지하철·규제·조례 같은 정책 키워드가 겹치면 "중간"
  - 그 외는 "낮음" (도장이 흐린 회색)
- 요약은 별도 AI 호출 없이, 서울시가 보도자료에 원래 쓰는 `□`, `○` 핵심 문장을 그대로 뽑아 보여줍니다.
  (서울시 보도자료가 이미 그런 구조로 작성되기 때문에 정확도가 높고 비용이 들지 않습니다.)
- 결과는 `data/news.json` 에 최신순으로 최대 400건까지 쌓입니다.
- `index.html` 은 이 JSON만 읽어서 화면에 뿌리는 정적 페이지라, 여는 순간 추가 요청 없이 바로 보입니다.

## 사이트 개편으로 스크립트가 깨지면

Actions 로그에 빨간 글씨로 오류가 뜹니다. 그 메시지를 그대로 복사해서 Claude에게 붙여넣어 주시면
서울시 사이트 구조 변경에 맞춰 `scraper/scrape_seoul.py`를 같이 고칠 수 있어요.

## 나중에 다른 지역(경기도, 대전 등)을 추가하려면?

지금은 서울시만 연결되어 있어요. 구조가 확인되는 대로 지역별 스크립트를
`scraper/` 폴더에 하나씩 추가하고, `scrape_seoul.py`가 만든 것과 같은 형식으로
`data/news.json`에 합쳐 넣으면 됩니다.

## ⚠️ 파일을 실수로 덮어썼다면

GitHub는 커밋 기록이 남아있어서 복구할 수 있습니다.
1. 저장소에서 문제의 파일(예: `index.html`) 클릭
2. 우측 상단 시계 아이콘(History) 클릭
3. 덮어쓰기 **전** 커밋을 찾아 클릭 → **Raw** 버튼으로 원본 확인/복사
