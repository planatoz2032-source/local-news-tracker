# 지역 보도자료 모음 사이트 — 설치 안내

이 폴더 안의 파일들을 GitHub에 올리면, 하루 2번(0시, 12시) 자동으로
서울시 보도자료(주택·교통·도시계획)를 가져와서 웹사이트에 보여줍니다.

아래 순서대로만 따라 하시면 됩니다. (전부 웹브라우저에서 마우스 클릭으로 진행)

---

## 1단계. 새 저장소(Repository) 만들기

1. github.com 로그인 후, 우측 상단 **+** 버튼 → **New repository** 클릭
2. Repository name에 원하는 이름 입력 (예: `local-news-tracker`)
3. **Public** 선택 (Pages 무료 호스팅을 쓰려면 Public이어야 해요)
4. **Create repository** 클릭

## 2단계. 파일 업로드

1. 방금 만든 저장소 페이지에서 **Add file → Upload files** 클릭
2. 이 폴더(`seoul-news-tracker`) 안의 내용물을 **전체 드래그해서** 업로드 화면에 끌어다 놓기
   - `.github` 폴더, `scraper` 폴더, `data` 폴더, `index.html`, `README.md` 가 모두 포함되어야 해요
   - 폴더째로 끌어놓으면 GitHub가 폴더 구조를 그대로 인식합니다
3. 하단의 **Commit changes** 클릭

> ⚠️ `.github` 폴더처럼 점(.)으로 시작하는 폴더가 안 보이는 파일 탐색기를 쓰신다면,
> 폴더 보기 설정에서 "숨김 파일 표시"를 켜주세요. (Mac: `Cmd+Shift+.`, Windows 탐색기: 보기 → 숨긴 항목)

## 3단계. 자동 실행(Actions) 켜기 & 첫 실행해보기

1. 저장소 상단 메뉴에서 **Actions** 탭 클릭
2. "서울시 보도자료 수집" 워크플로우가 보이면 클릭
3. 우측의 **Run workflow** 버튼 클릭 → 다시 **Run workflow** 클릭 (수동으로 1회 실행)
4. 1~2분 기다리면 초록 체크(✅)가 뜨는지 확인 — 이게 뜨면 정상적으로 데이터를 가져온 것입니다
5. 만약 빨간 X가 뜨면, 그 항목을 클릭해서 나오는 로그(빨간 글씨 오류 메시지)를 저에게 복사해서 붙여넣어 주세요. 같이 고치겠습니다.

이후에는 매일 자동으로 0시, 12시에 실행됩니다. (별도 조작 필요 없음)

## 4단계. 웹사이트 켜기 (GitHub Pages)

1. 저장소 상단 **Settings** 탭 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. "Build and deployment" 항목에서 **Source: Deploy from a branch** 선택
4. Branch를 **main**, 폴더는 **/(root)** 선택 → **Save**
5. 1~2분 후 상단에 나오는 주소 (`https://내아이디.github.io/저장소이름/`) 로 접속하면 웹사이트가 보여요

이 주소를 핸드폰 홈 화면에 즐겨찾기로 추가해두시면, 앱처럼 바로 열어볼 수 있어요.

---

## 나중에 다른 지역(경기도, 대전 등)을 추가하려면?

지금은 서울시만 연결되어 있어요. 구조가 확인되는 대로 지역별 스크립트를
`scraper/` 폴더에 하나씩 추가하고, `index.html` 안의 `DATA_SOURCES` 목록에
한 줄씩 추가하면 됩니다. 이 부분은 다음 단계에서 같이 진행해요.

## 궁금한 점이 생기면

- Actions 실행이 실패하면: 로그의 오류 메시지를 그대로 복사해서 보여주세요.
- 화면이 이상하게 보이면: 어떤 화면인지 캡처해서 보여주세요.
- 데이터가 이상하면(제목이 이상하게 잘리는 등): 어떤 게시물인지 알려주세요.
