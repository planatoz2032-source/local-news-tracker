# 서울시 보도자료 — 놓치지 않기

3시간마다(하루 8번) 자동으로 서울시 보도자료를 가져와서,
- 주택·교통은 전부, 그 외 분야는 정책적으로 중요해 보이는 것만 골라서
- 제목 옆에 중요도 도장을 찍고
- 클릭하면 핵심 내용(□, ○ 로 시작하는 문장)을 바로 보여주는 사이트입니다.

첫 화면에서 서울시 사이트를 매일 다시 훑어볼 필요 없이, 이 페이지 하나만 확인하면 됩니다.

---

## 1단계. 새 저장소 만들기

1. github.com 로그인 후, 우측 상단 **+** → **New repository**
2. 이름은 원하는 대로 (예: `local-news-tracker`)
3. **Public** 선택 (GitHub Pages 무료 호스팅 조건)
4. **Create repository**

## 2단계. 파일 업로드

1. 저장소 페이지에서 **Add file → Upload files**
2. 이 폴더 안의 내용물(`.github`, `scraper`, `data`, `index.html`, `README.md`)을 **전체** 드래그해서 업로드
   - `.github` 폴더가 안 보이는 파일 탐색기라면 "숨김 파일 표시"를 켜주세요
     (Mac: `Cmd+Shift+.`, Windows 탐색기: 보기 → 숨긴 항목)
3. **Commit changes**

## 3단계. Actions 켜기 & 첫 실행

1. 저장소 상단 **Actions** 탭
2. "서울시 보도자료 수집" 워크플로우 클릭
3. 오른쪽 **Run workflow** → 다시 **Run workflow** (수동 1회 실행)
4. 1~2분 후 초록 체크(✅)가 뜨면 성공
   - 빨간 X가 뜨면 클릭해서 나오는 로그(빨간 글씨)를 통째로 복사해서 Claude에게 붙여넣어 주세요
5. 이후로는 3시간마다 자동 실행됩니다 (별도 조작 불필요)

## 4단계. 웹사이트 켜기 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)** → **Save**
3. 1~2분 후 나오는 주소(`https://내아이디.github.io/저장소이름/`)로 접속

핸드폰 홈 화면에 즐겨찾기 해두면 앱처럼 바로 열립니다.

---

## 어떻게 작동하나요

- `scraper/scrape_seoul.py` 가 서울시 보도자료 목록을 훑어서 새 글만 골라내고,
  각 글의 상세페이지(`분류`, 본문 핵심 문장)를 가져옵니다.
- **중요도 판정 기준**
  - 분류가 `주택` 또는 `교통`이면 무조건 "높음"
  - 다른 분야라도 제목에 부동산·정비사업·지하철·규제·조례 같은 정책 키워드가 겹치면 "중간"
  - 그 외는 "낮음" (도장이 흐린 회색)
- 요약은 별도 AI 호출 없이, 서울시가 보도자료에 원래 쓰는 `□`, `○` 핵심 문장을 그대로 뽑아 보여줍니다.
  (서울시 보도자료가 이미 그런 구조로 작성되기 때문에 정확도가 높고 비용이 들지 않습니다.)
- 결과는 `data/news.json` 에 최신순으로 최대 400건까지 쌓입니다.
- `index.html` 은 이 JSON만 읽어서 화면에 뿌리는 정적 페이지라, 여는 순간 추가 요청 없이 바로 보입니다.

## 사이트 개편으로 스크립트가 깨지면

Actions 로그에 빨간 글씨로 오류가 뜹니다. 그 메시지를 그대로 복사해서 Claude에게 붙여넣어 주시면
서울시 사이트 구조 변경에 맞춰 `scraper/scrape_seoul.py`를 같이 고칠 수 있어요.

## 화면 구성

- 왼쪽 사이드바: 지역 목록 (아직 연결 안 된 지역은 "준비중"으로 흐리게 표시)
- 검색창: 제목·부서·분야로 즉시 필터링
- 분야 필터: 실제 쌓인 데이터에서 자동으로 만들어짐 (주택/교통/경제/문화 등)
- 제목 옆 ★: 클릭하면 즐겨찾기 표시 + (설정했다면) 구글 시트에 자동 저장
- 왼쪽 작은 점: 중요도 표시 (빨강=높음, 갈색=중간, 회색=낮음)

## 즐겨찾기를 구글 시트에 쌓기

1. 새 구글 스프레드시트를 하나 만든다 (이름 아무거나, 예: `보도자료 즐겨찾기`)
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 기본 코드를 전부 지우고, 이 폴더의 `google-apps-script/Code.gs` 내용을 그대로 붙여넣기
4. 저장(💾) → 상단 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. **배포** 클릭 → 나오는 웹 앱 URL을 복사
6. `index.html` 파일을 열어서 아래 줄을 찾아 URL을 붙여넣기
   ```js
   const FAVORITES_WEBAPP_URL = ""; // 여기에 붙여넣기
   ```
7. 수정한 `index.html`을 GitHub에 다시 업로드(덮어쓰기) → Commit changes

이후로는 ★을 누를 때마다 그 스프레드시트에 자동으로 새 줄(지역·분야·제목·부서·등록일·링크)이 추가됩니다.
즐겨찾기 자체는 브라우저에도 저장되므로, URL을 아직 연결하지 않아도 ★ 기능은 정상 작동해요 (구글 시트에만 안 쌓일 뿐).

## 서울시 "위원회" 안건표를 구글 시트에 자동 기록하기

제목에 "위원회"가 들어간 서울시 보도자료(예: 도시계획위원회, 정비사업 통합심의위원회 등)는
대부분 첨부된 한글(.hwp) 파일 안에 "안건명 / 안건개요 / 심의결과 / 비고" 표가 들어있습니다.
이 표를 안건 한 줄씩 자동으로 구글 시트 "위원회" 탭에 기록하는 기능이에요.

**⚠️ 참고**: 한글 파일 구조를 실제로 열어보고 테스트하지 못한 상태로 만든 기능이라,
처음엔 한 번에 잘 안 될 수 있어요. 실패해도 서울/인천/대전 등 다른 수집 기능에는 영향이 없도록
안전하게 분리되어 있으니, 안 되면 Actions 로그(특히 "위원회" 관련 줄)를 복사해서 Claude에게
붙여넣어 주세요.

**설정 방법**
1. 위의 "즐겨찾기를 구글 시트에 쌓기"를 먼저 완료해서 같은 구글 시트에 Web App URL을 하나 만들어둔다
2. `scraper/scrape_seoul.py` 파일을 열어서 아래 줄을 찾아 같은 URL을 붙여넣기
   ```python
   COMMITTEE_WEBAPP_URL = ""  # 여기에 붙여넣기
   ```
3. 수정한 파일을 GitHub에 다시 업로드 → Commit

이후로는 위원회 관련 새 글이 올라올 때마다 안건별로 "위원회" 탭에
날짜·위원회구분·회차·안건명·안건개요·심의결과·비고·링크가 자동으로 쌓입니다.
(비워두면 이 기능은 그냥 건너뛰고, 나머지 수집은 평소대로 진행돼요.)

## 나중에 다른 지역(경기도, 대전 등)을 추가하려면?

1. `data/regions.json`을 열어서 추가하려는 지역의 `"status": "coming"`을 `"status": "active"`로 바꾸고, `"file": "news_지역이름.json"`을 지정
2. `scraper/scrape_seoul.py`를 복사해서 그 지역 사이트에 맞게 고친 새 스크립트를 `scraper/`에 추가 (URL 구조, REGION_ID, REGION_NAME, NEWS_JSON 경로만 바꾸면 됨)
3. `.github/workflows/scrape.yml`에 그 스크립트를 실행하는 단계를 추가
4. 사이트를 새로고침하면 사이드바에 자동으로 그 지역이 활성화되어 나타납니다

구조가 확인되는 대로 이 부분은 Claude와 함께 하나씩 진행하면 돼요.

## ⚠️ 파일을 실수로 덮어썼다면

1. 저장소에서 문제의 파일(예: `index.html`) 클릭
2. 우측 상단 시계 아이콘(History) 클릭
3. 덮어쓰기 **전** 커밋을 찾아 클릭 → **Raw** 버튼으로 원본 확인/복사
